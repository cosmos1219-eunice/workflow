# 평가 기준표

## 1. 기계 검사 (validate_brief.py)

| 구분 | 규칙 | 실패 시 |
|---|---|---|
| 출처 존재 | 현황·이슈·타임라인의 `sources`가 모두 `articles.json`의 id | 오류 (환각 출처) |
| 기간 | 인용 기사·타임라인 날짜가 수집 기간 안 | 오류 |
| 신호 강도 | `high`는 서로 다른 언론사 2곳 이상(`also_in` 포함) | 오류 → `medium`으로 낮추거나 출처 보강 |
| 팩트체크 | `REJECTED` 포함 금지, `WEAKENED`/`UNCERTAIN`은 `check_note` 필수 | 오류 |
| 시사점 | `so_what`·`for_client`·`next_action` 필수, `so_what` ≠ 제목, 근거 이슈 id 실재 | 오류 |
| 개수 | 요약 3, 현황 3–8, 이슈 3–7, 시사점 3–5, 관찰 3–5, 타임라인 5–15 (기사 30건 미만이면 완화) | 오류 |
| 리뷰 | 6개 기준 각 ≥ 7, 평균 ≥ 8 | 오류 |
| 수치 | 수치가 있는 이슈인데 `CONFIRMED`가 아님 | 경고 + 보고서에 "수치 미확인" |
| 관점 편중 | 이슈가 4개 관점 중 2개 이하에만 있음 | 경고 |
| 기간 편중 | 인용 기사가 한 달에만 있음 | 경고 |
| 균형 | 시사점이 모두 `opportunity` | 경고 |
| 수집 한계 | 실패 구간·상한 도달일이 있는데 `limitations`에 없음 | 경고 |

판정은 점수가 아니라 규칙이다. 오류가 하나라도 있으면 FIX이고, 보고서를 만들지 않는다(`--force` 초안 제외).

## 2. 파트너 리뷰 채점표 (각 10점)

| 기준 | 10점 | 7점 | 4점 이하 |
|---|---|---|---|
| **최신성** `recency` | 3개월 흐름이 보이고, 최근 2주의 변화가 요약 첫 줄에 있다 | 최신 소식은 있지만 흐름(이전 → 지금)이 약하다 | 최근 몇 주에 몰렸거나 오래된 소식이 앞에 온다 |
| **근거성** `evidence` | 모든 사실에 출처, 사실/해석 구분이 분명, 수치는 원문 확인 | 출처는 있으나 일부 해석이 사실처럼 쓰였다 | 출처 없는 단정, 헤드라인 숫자 그대로 인용 |
| **구조화** `structure` | 현황 영역이 겹치지 않고 빠짐없다(MECE), 이슈 간 중복 없음 | 영역 하나가 겹치거나 빠졌다 | 기사 나열 수준 |
| **시사점 깊이** `so_what` | 각 시사점이 "그래서 무엇이 달라지는가"를 말하고 2차 효과(경쟁사·고객·밸류체인)까지 본다 | 방향은 맞지만 일반론("경쟁 심화 예상")이 섞였다 | 뉴스를 다시 말할 뿐이다 |
| **실행 가능성** `actionability` | 다음 행동이 구체적: 누구에게(IR, 업계 전문가, 고객사) 무엇을 물을지, 어떤 자료(공시, 실적 발표)를 볼지, 어떤 가설을 고칠지 | 행동은 있으나 막연하다("모니터링 필요") | 행동이 없다 |
| **균형** `balance` | 회사 발표와 외부 시각, 긍정·부정 보도를 함께 다루고 리스크 시사점이 있다 | 한쪽으로 기울었지만 반대 시각을 언급한다 | 보도자료 요약 수준 |

통과: **모든 기준 ≥ 7, 평균 ≥ 8.** 미달이면 약한 부분만 고쳐 다시 채점(최대 2회). 두 번째에도 미달이면 미달 기준과 이유를 보고서 한계에 적고 그대로 전달하지 않는다 — 사용자에게 무엇이 부족한지(예: 원문 접근 실패로 근거성 6점) 알리고 진행 여부를 묻는다.

## 3. 시사점 품질의 예

| 나쁨 (뉴스 반복) | 좋음 (so what → 고객에게 → 다음 행동) |
|---|---|
| "ESS 입찰에 불참했다. 향후 동향을 지켜볼 필요가 있다." | So what: 저가 수주 대신 마진을 택한 것으로, 국내 ESS 시장에서 가격 결정권이 경쟁 2사로 넘어간다. 고객에게: 국내 ESS 공급사 선정 시 협상 구도가 2파전으로 바뀐다. 다음 행동: 경쟁 2사의 3차 입찰 가격 수준을 결과 발표 후 확인하고, IR에 북미 ESS 가동률 목표를 질문 목록에 넣는다. |
| "실적이 개선되었다. 긍정적이다." | So what: 개선의 원인이 일회성(보조금·환율)인지 구조적(제품 믹스)인지에 따라 내년 가정이 달라진다. 다음 행동: 실적 발표 자료에서 보조금 효과를 뺀 영업이익률을 계산해 모델에 반영한다. |
